# Project: aislop-vs-noslop

A side-by-side comparison: `aislop/` is a maximally generic AI-slop landing page.
`noslop/` is the same kind of page built under the antislop filter.

## antislop

The antislop skill set is installed in `.codebuddy/skills/` and loads automatically:

- Core filter: `.codebuddy/skills/antislop/SKILL.md`
- UI / visual: `.codebuddy/skills/antislop-ui/SKILL.md`
- Copy & text: `.codebuddy/skills/antislop-copywriting/SKILL.md`
- People (a11y): `.codebuddy/skills/antislop-human/SKILL.md`
- Mobile / responsive: `.codebuddy/skills/antislop-layoutmobile/SKILL.md`
- Code comments: `.codebuddy/skills/antislop-code/SKILL.md`

For any UI, copy, people, mobile-layout, or code-comment work in this repo, follow
the antislop rules (the Delivery Gate in the core SKILL.md is mandatory before shipping).
Before starting such work, ask when antislop applies: during the work, or after it is done.
